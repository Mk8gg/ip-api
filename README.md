# Hy2 Manager

一键部署 sing-box 1.14.x + Hysteria2 + ACME + ECH，并提供轻量 Web 面板。

## 安装

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Mk8gg/ip-api/master/install.sh)
```

安装时输入自己的域名和 Hysteria2 密码。项目不会写入任何固定域名、IP、密码或 ECH 私钥。

## 特性

- Debian 13
- 官方 sing-box 安装脚本
- Hysteria2
- Let's Encrypt ACME 自动签发/续期
- ECH
- IPv4/IPv6
- systemd
- Web 管理面板
- 节点 URI
